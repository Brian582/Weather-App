# Weather-App

This weather app allows users to search for the weather in a state,city, or country.

The app uses an API called OpenWeatherMap to retrieve the weather data needed for the app.

It first needs to make a call to the GeoCoding API to get the longitude and latitude of the state, city, or country. 
After that, it makes a call to the OpenWeatherMap API to get the weather data.

This weather app displays the weather, description of the weather, temperature, humidity, and wind speed.

To run the weather app, you need to download JavaFx Scenebuilder and add a JSON library.

You also need to get an API key from the OpenWeatherMap website in order to run the weather app.
